## 2024-06-12 - Explicit styling for disabled elements and focus indicators
**Learning:** Native `button:disabled` elements often require manual intervention to fully convey their non-interactive state visually. Furthermore, focus rings are not universally styled across vanilla CSS codebases, requiring explicit `focus-visible` styling for robust keyboard accessibility. In addition, providing a `title` (or a tooltip) to disabled action buttons ensures users are not frustrated when trying to determine *why* a function is currently blocked.
**Action:** When implementing a design system in a vanilla CSS environment, ensure global button styles include explicitly targeted `:not(:disabled):hover` (so they don't seem interactive), `:disabled` (opacity, grayscale, not-allowed cursor), and `:focus-visible` (clear visual outline) rules. Always add descriptive tooltips to disabled state buttons.
