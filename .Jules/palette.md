## 2024-10-05 - Disabled Button Clarity
**Learning:** Buttons like "Limpar Lista" and "Restaurar Lista" in this vanilla HTML/JS project had specific descriptive classes (`.warning`, `.secondary`), but those classes were not actually defined in the CSS. Additionally, disabled states lacked visual feedback, meaning an unclickable action looked identical to a clickable one, frustrating users who didn't understand why nothing happened on click.
**Action:** Implemented clear styles for disabled buttons using `button:disabled { opacity: 0.5; cursor: not-allowed; filter: grayscale(100%); }`, suppressed hover effects on disabled buttons, added styles to missing semantic classes, and provided a dynamic `title` attribute using JavaScript to explicitly communicate *why* an element is disabled (e.g. "Nenhuma lista anterior para restaurar").
